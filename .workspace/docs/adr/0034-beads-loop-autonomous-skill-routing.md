# 0034. Beads loop autonomous skill routing

## Contexto
La ejecución de /beads-loop se interrumpió porque el agente añadió gates de brainstorming, worktree, árbol limpio y aprobación ajenos al adaptador.

## Decisión
Cada Bead reclamado se ejecutará autónomamente mediante el adaptador; se aplicarán sólo las skills Superpowers pertinentes durante el Bead y se excluirá brainstorming como gate.

## Alternativas descartadas
Mantener gates conversacionales o de aislamiento por Bead: descartado porque corta el ciclo canónico; omitir Superpowers: descartado porque reduce la disciplina por tipo de trabajo.

## Consecuencias
Los tests de contrato prueban la guía contra gates ajenos.
